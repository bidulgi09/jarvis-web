카드 없이 무료: console.groq.com/keys 에서 GitHub나 Google로 로그인 → Create API Key. 무료 한도는 큰 모델 기준 하루 약 1,000번입니다.

카드 등록 없이 무료로 받을 수 있습니다: aistudio.google.com/apikey → Create API key. 무료 등급은 대화 내용이 Google 서비스 개선에 쓰일 수 있습니다.

키는 console.anthropic.com에서 발급합니다.

키는 이 브라우저에만 저장되고 해당 회사 서버로만 보내집니다. 공용 컴퓨터에서는 넣지 마세요.

Supertonic은 처음 한 번 음성 모델을 받아 저장해 두고, 이후에는 인터넷 없이도 기기 안에서 목소리를 만듭니다. 받는 동안에는 브라우저 기본 음성으로 말합니다.
